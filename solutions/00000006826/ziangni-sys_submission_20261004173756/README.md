# Disproof of conjecture 00000006826

The complex identity on C² is upper triangular but has only the zero and whole hyperinvariant subspaces. Actual rank-one continuous linear maps send any nonzero vector to any target and commute with identity. Thus no one-dimensional hyperinvariant intermediate subspace exists for a complete triangularizing flag. Ordinary Schur triangularization remains valid.
