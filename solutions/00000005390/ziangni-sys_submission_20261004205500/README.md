# Disproof of conjecture 00000005390

Bijective pointwise conjugacy universally preserves every iterate-fixed point set, exact/minimal period, directed reachability relation, and actual unrooted periodic cycle collection. Therefore the source's required conjugate pair cannot have different corresponding periodic dynamics, irrespective of its height constraints.

Lean supplies actual point and cycle equivalences, cardinal and finite-count equalities, orbit-image identities and an impossibility theorem with arbitrary additional restrictions.

This addresses periodic structure up to dynamical isomorphism, not mere coordinate locations or equivalence only almost everywhere. It does not rule out unconjugated maps with the same heights and different periodic structures.
