## Semantic audit

The conjecture identifies the worst-case step count of the simplex method with the polytope diameter. Both language versions assert this identification without restricting the method to a shortest-path-following pivot rule. The submission takes the canonical instantiation — Dantzig's original largest-positive-reduced-cost rule — and exhibits the LP maximizing z = 2x + y over P = {x ≥ 0, y ≥ 0, x ≤ 5, 4x + y ≤ 25}, the smallest member of the Klee–Minty family. The Lean formalization works with the real halfspace set `P` (not a proxy), proves P is convex, classifies `P.extremePoints ℝ` exhaustively as {(0,0), (5,0), (5,5), (0,25)} via `full_vertex_set` (both inclusions, using open-segment arguments for non-extremality and weighted-average lemmas for extremality), proves full-dimensionality (`full_dimensional`), and defines adjacency by a **nonzero supporting linear functional** attained at both vertices (`Edge`), which for a full-dimensional polytope is exactly graph adjacency since a proper face containing two vertices is an edge. `edges_exact` proves `Edge i j ↔ cycle.Adj i j` for the 4-cycle, and `diameter_two` computes Mathlib's `SimpleGraph.diam` to be exactly 2.

The simplex side is equally faithful. Slacks x + s = 5, 4x + y + t = 25 give four dictionaries D0–D3, formalized as functions `dictionary k u` that are proved (`dictionary_eqns`, `dictionary_complete`) to satisfy the standard-form equations for **every** equality-feasible vector and to recover their nonbasic coordinates — not just point values at vertices. `basis_partition` proves each dictionary's nonbasic/basic split is a bijection onto the four variables; `nondegenerate` proves strict positivity of basic coordinates. Each pivot is certified as a genuine Dantzig step: `unique_entering` (strictly largest positive reduced cost, unique entering variable), `exact_ratio_test` (the complete feasible ray interval is exactly [0,5], i.e. the maximal step), `unique_leaving` (exactly one basic variable vanishes at the endpoint, so no degeneracy or tie-breaking), and `pivot_endpoint` (the endpoint dictionary is the next vertex's dictionary). `terminal_reduced_costs` shows both terminal reduced costs are negative and `terminal_unique_optimum` proves objective p ≤ 25 on P with equality iff p = (0,25), so the run genuinely terminates at the unique optimum. The final certificate `simplex_counterexample` combines: all three pivots are Dantzig-pivots, the terminal dictionary is optimal, the walk length is 3 (= card (Fin 3)), and `cycle.diam < 3`. Since every choice is unique, the three-step run is forced, so the worst-case step count on this instance is at least 3 while the diameter is 2 — exactly the negation of the asserted identity. The report's Scope paragraph honestly states that only the equality conjunct is refuted and that other pivot rules are not claimed to take three steps; this is sound because falsifying one conjunct of the stated conjunction suffices.

Independent mathematical verification with exact rational arithmetic in Python confirmed: the four vertices are feasible; the four facet-supporting functionals give exactly the 4-cycle edges while no nonzero functional supports {v0, v2} or {v1, v3} (no diagonals); the graph diameter is 2; the objective values along the run are 0, 10, 15, 25 with the unique optimum 25 at (0,25); and 2x + y ≤ (4x + y) − 2x ≤ 25 holds on a fine grid with no violations. The dictionary algebra in the report (s = 5 − x, t = 25 − 4x − y; z = 10 − 2s + y; z = 15 + 2s − t; z = 25 − 2x − t) was checked by hand and matches the Lean `reduced`/`value` tables and the `dictionary_objective` identity.
