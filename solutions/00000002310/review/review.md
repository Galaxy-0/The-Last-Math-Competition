## Semantic audit
The conjecture's first conjunct states that the supremum of the base size b(G) over almost simple groups is 7, attained by the action of Sp₈(2). The text defines b(G) as the minimal size of a base (a set of points with trivial pointwise stabilizer), i.e. b is a base size of a permutation action, and the stated class is "almost simple groups" with no restriction to non-standard actions. The submission takes the narrowest standard interpretation of the class — finite almost simple groups acting faithfully and primitively on a finite set — and disproves the claim inside it: the natural action of A_n on n points belongs to this class for every n ≥ 5 and has base size exactly n − 2, which is unbounded. Hence the supremum is ∞ (formalized as `sSup almostSimpleBaseSizes = ⊤` in ℕ∞), not 7, and `conjecture_2310_false` is the exact negation of the conjunct; `conjecture_2310_false_A10` additionally gives the concrete witness A₁₀ with b = 8 > 7.

The formalization is faithful to the conjecture's own objects. A base and the base size are defined on an arbitrary group action (`IsBase`, `baseSize` via an infimum over finite bases); almost simplicity is the standard abstract condition (a nonabelian simple normal subgroup with trivial centralizer, embedding T ≅ Inn(T) ≤ G ≤ Aut(T)); and for A_n everything is proved from first principles: any set B of at most n − 3 points misses three distinct points a, b, c and the even permutation (ab)(bc) fixes B pointwise but moves c, so B is not a base; conversely an even permutation fixing n − 2 points has support of size ≤ 2, and supports of size 1 are impossible for permutations while size 2 gives an odd transposition, so the complement of any two points is a base. Hence b(A_n) = n − 2 for all n ≥ 2 (`baseSize_alternating`). Simplicity of A_n for n ≥ 5 is Mathlib's `alternatingGroup.isSimpleGroup`; noncommuting elements witnessing nonabelianness and triviality of the center (a proper normal subgroup of a simple group) are constructed explicitly; primitivity for n ≥ 3 is Mathlib's `alternatingGroup.isPreprimitive_of_three_le_card`; faithfulness is inherited from the permutation action.

The mathematics was independently sanity-checked and is classical: the pointwise stabilizer in A_n of k points is A_{n−k} (trivial exactly when k ≥ n − 2), so b(A_n) = n − 2. The report is explicit and honest about scope in two respects: enlarging the class (dropping primitivity or finiteness) only increases the supremum, so the narrowest reading is the strongest case for the conjecture; and if the intended class were restricted to non-standard actions — as in the literature theorem about b ≤ 7, which excludes natural actions of classical and alternating groups — the counterexample would not apply, but the conjecture text states no such restriction. Only the first conjunct is refuted; the "exactly 3 groups" exception-table claim is not addressed. This repairs precisely the vacuity for which PR #222 was rejected (a single exhibited non-base 7-subset and numeral decisions), here replaced by a proof that every set of at most n − 3 points fails to be a base.
