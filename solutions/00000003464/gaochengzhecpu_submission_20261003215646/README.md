# Conjecture 00000003464: Disproof

The single-edge graph K2 has maximum degree 1 and minimum L(2,1)-labeling span 2: its adjacent labels must differ by at least two, and labels 0 and 2 attain that span. Hence lambda(K2)=2>1=Delta(K2)^2.

## Scope

This refutes the universal bound as written, since neither source language assumes Delta>=2. It does not refute the classical degree-squared conjecture with that additional restriction, and it makes no claim about the separate asymptotic or Moore-graph assertions.
