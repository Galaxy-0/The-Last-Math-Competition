# Disproof of conjecture 00000003964

The prime-order cyclic group Z/1021Z is simple and generated by 1.
Its undirected Cayley graph has actual distance at least 510 between
0 and 510, hence diameter at least 510. Both 3(ln 1021)^2 and
3(log_2 1021)^2 are strictly less than 300. This disproves the universal
upper bound stated in both languages of the source.

## Reproduction

With Lean 4.19.0 and the supplied public-Git, commit-pinned dependencies:

```text
cd lean
lake exe cache get
lake build
lake env lean -DwarningAsError=true Main.lean
```

The cache command is optional if dependencies have already been built.
Compile main.tex with Tectonic or a compatible LaTeX installation.
No supplementary numerical program is needed.

## Scope and artifacts

SOURCE.md contains the exact bilingual source. main.tex/main.pdf contain
the complete proof. The Lean project uses the actual simple additive
group ZMod 1021, subgroup closure, the actual Cayley cycle, actual walks
and Mathlib graph distances. Diameter is the finite maximum of the
distances. The logarithmic comparisons and the negation of the universal
bound are proved directly.

The source does not restrict its claim to nonabelian simple groups.
Cyclic groups of prime order are simple under the standard definition.
This submission does not claim to refute a nonabelian-only variant or
settle the additional PSL(2,p) extremal-family clause.

The verification directory contains an author self-review and a
distinct delegated agent's internal review, together with
actual fresh compilation, direct Lean and standard axiom logs, source
provenance, and final PDF inspection. No external independent review is
claimed. No custom axiom, sorry, admit or native_decide is used.
