\section{Conjecture \#1203: subtraction-game periods}

\begin{conjecture}[TLMC-00000001203]\label{conj:1203}
Let $S \subseteq \{1, \dots, k\}$ be the move set of a subtraction game with Sprague--Grundy sequence $g$, and let the period be the least positive period of $g$. Then the period divides $2^k - 1$ if and only if $S$ is nonempty and does not contain $k$; when $k \in S$ the period is exactly $k+1$.
\end{conjecture}

\begin{theorem}\label{thm:1203}
Conjecture~\ref{conj:1203} is \textbf{false}. For $S = \{1\}$ and $k = 2$ the SG sequence is $g(n) = n \bmod 2$ with minimal period $2$, the set $S$ is nonempty and does not contain $2$, yet $2 \nmid 2^2 - 1 = 3$.
\end{theorem}

\begin{proof}
For the subtraction game with $S = \{1\}$, position $n+1$ has the single option $n$, so $g(n+1) = \operatorname{mex}\{g(n)\}$ with $g(0) = 0$. By induction, $g(n) = n \bmod 2$: indeed $\operatorname{mex}\{0\} = 1$ and $\operatorname{mex}\{1\} = 0$, so the values alternate $0, 1, 0, 1, \dots$. The minimal period of this sequence is $2$: it is periodic with period $2$ since $(n+2) \bmod 2 = n \bmod 2$, and it is not periodic with period $1$ since $g(0) = 0 \ne 1 = g(1)$.
Now take $k = 2$, so $S = \{1\} \subseteq \{1, 2\}$, $S \ne \emptyset$, and $k = 2 \notin S$. The conjecture predicts that the period $2$ divides $2^2 - 1 = 3$, which is false. This counterexample refutes the ``if and only if'' claim. (The companion claim also fails: for $S = \{2\}$, $k = 2$, the SG sequence is $g(n) = \lfloor n/2 \rfloor \bmod 2$ with minimal period $4 \ne k + 1 = 3$.)
\end{proof}
