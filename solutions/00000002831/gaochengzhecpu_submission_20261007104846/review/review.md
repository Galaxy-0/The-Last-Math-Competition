## Semantic audit

If a family of real polynomials vanished on `S`, then each `q_f(T) = f(T, 1−T)` would have infinitely many roots in `[0,1]`, hence be identically zero, so `f(2, −1) = 0` for every `f`; but `(2, −1)` is not in the image. Therefore the image is not a real algebraic set.

The Lean project formalizes a genuine stochastic `HMM` structure (with nonnegativity and row-sum constraints), the actual observation map as a finite sum, `modelImage`, and a valid HMM for every `t ∈ [0,1]`; it proves `(2,−1) ∉ modelImage`, and using genuine `MvPolynomial` evaluation and the finite-root theorem proves `conjecture_false : ¬ IsRealAlgebraic modelImage` — stronger than merely the absence of a single defining equation.
