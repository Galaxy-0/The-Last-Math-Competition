## Semantic audit
The conjecture asserts that in undirected vertex geography (token moved along edges, visited vertices deleted) the first player wins from a start vertex if and only if the start belongs to every maximum matching. Both language versions use "every/一切 maximum matching", which the submission reads as: saturating (being an endpoint of an edge of) every maximum-cardinality matching — the standard reading, and the one under which the statement is the known theorem attributed through Fraenkel–Scheinerman–Ullman and stated in Gates et al., Theorem 2.8. The report discloses rather than hides this attribution, and correctly declines to formalize the historical "extends the edge version" sentence.

The formalization matches the statement quantifier-for-quantifier. The game is a well-founded recursion `Wins G S v` on the number of available vertices: a position is winning iff there is a legal move to an adjacent still-available vertex (deleting the current one) whose successor is losing; with no legal move the position is losing — exactly normal play, with the token starting on an already-visited vertex. `FirstPlayerWins G start := Wins G Finset.univ start`, and the main theorem is the iff against `∀ M, MaximumMatching G Finset.univ M → Saturates M start` over an arbitrary `Fintype` vertex type with `DecidableEq`, no connectivity, nonemptiness or perfect-matching assumption; isolated starts are separately shown losing, and the empty vertex type is handled without extra hypotheses. Matchings are honest finite sets of `Sym2` edges of the `SimpleGraph`, maximum means largest edge cardinality among matchings on the available set (existence proved via the finite powerset filter), and `Saturates` means endpoint membership — no definition is weakened or strengthened relative to the source.

The mathematical proof is the classical induction and it is correct. I verified both directions of the key `essential_recurrence` by hand: (⇒) if every maximum matching on S saturates v, take a maximum M with edge vw; then N = M ∖ {vw} is a matching on S ∖ {v}; any matching L there is also a matching on S, so |L| ≤ |M|, and equality would exhibit a maximum matching of S missing v, contradicting essentiality; hence |L| ≤ |M| − 1 = |N|, so N is maximum on S ∖ {v} and misses w, giving ¬Essential(S∖{v}, w). (⇐) if vw is legal and N is maximum on S ∖ {v} missing w, then K = N ∪ {vw} is a matching on S of size |N| + 1; a maximum matching M of S missing v would be a matching on S ∖ {v}, forcing |M| ≤ |N| < |K| ≤ |M|, a contradiction. Since `Wins` and `Essential` satisfy the identical one-move recurrence over the same strictly decreasing positions, the general uniqueness lemma `wins_iff_of_recurrence` (strong induction on the Finset) identifies them at every valid residual position — a stronger statement than needed, since the initial position is the special case S = univ. The exhaustive Python check up to six vertices independently corroborates the theorem on 202,013 concrete positions with zero mismatches, including all disconnected and isolated-start cases.
