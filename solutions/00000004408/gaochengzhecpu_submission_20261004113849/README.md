# Conjecture 00000004408: counterexample

**Result:** the graphon `W(x,y)=xy` on `[0,1]^2` has no finite-step representative under the source's measure-preserving-transformation / almost-everywhere equivalence. In fact, every equivalent representative fails to be essentially countably valued.

For every countable set `S`, the inverse image `{(x,y):xy in S}` has product measure zero: for almost every fixed `x`, its vertical section is countable. The distribution of function values is unchanged under simultaneous measure-preserving relabelling and null modification, hence under the equivalence relation they generate. Every finite-step graphon has finite essential range, giving a contradiction.

## Reproduce

Install the official Lean toolchain named in `lean/lean-toolchain`. With Git/network access for the locked Mathlib dependency:

```text
cd lean
lake update
lake exe cache get Mathlib/MeasureTheory/Measure/Prod.lean Mathlib/MeasureTheory/Measure/Lebesgue/Basic.lean Mathlib/Tactic/NormNum.lean
lake build
lake env lean -DwarningAsError=true Main.lean
```

`lake update` reads the exact Mathlib commit in `lakefile.toml`; keep `lake-manifest.json` under version control. A local `.lake` directory is a build/cache directory and is not part of the portable source package. Compilation of this submission was also run from a fresh directory containing no submission build artifacts.

From the package directory, a standard LaTeX installation or Tectonic can compile the paper:

```text
tectonic --keep-logs main.tex
```

The native desktop compiler is unavailable on this host; the supplied PDF is an actual Tectonic export, rendered and visually inspected page by page.

## Exact Lean coverage

Lean checks the probability and nonatomic measure instances, measurability/symmetry/unit-square range of `xy`, the null inverse image of **every countable** set, pushforward-law invariance under both generating operations, invariance under the full `Relation.EqvGen`, and nonexistence of any finite-step representative. The only printed axioms are Lean's standard `propext`, `Classical.choice`, and `Quot.sound`.

The ambient carrier is the real line with Lebesgue measure restricted to `[0,1]`; values outside the interval are irrelevant. `HasFiniteStepForm` is deliberately an algebraic necessary condition: a finite block-index map and a matrix of weights give the kernel almost everywhere. It permits even nonmeasurable block-index maps. Consequently the negative theorem applies to the usual, more restrictive measurable-partition definition. The manuscript explains the routine translation from a finite partition to its index map and the restricted-measure model. Neither nonexistence nor invariance is assumed.

The theorem uses exactly the equivalence generated by null modification and measure-preserving relabellings; it makes no claim about an unspecified topological/orbit closure. Failure of exact representation is compatible with approximation by step graphons.

## Scope

The original wording does not explicitly say “finite”, but minimal finite step count has its standard finite-partition meaning. The same counterexample excludes countably many constant block rectangles. Allowing uncountably many singleton blocks would change the proposed meaning of step count, and is not needed to interpret the conjecture in its usual form. The universal existence assertion is false, so the conjunction is false; this package does not separately adjudicate the informal “jump count” assertion on a restricted class.

No submission or upstream changes are made by this package.
