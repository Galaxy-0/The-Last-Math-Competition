## Semantic audit

The conjecture's main clause reads: "For bipartite graphs, depth is at least ν + 1", where depth is depth R/I(G) and ν is the matching number. The submission refutes this clause with the smallest possible bipartite graph, K₂, and the refutation is exact: K₂ is bipartite, ν(K₂) = 1 (the single edge is a matching; a matching subgraph of K₂ has at most one edge), I(K₂) = (xy) ⊆ k[x,y], and depth_m k[x,y]/(xy) ≤ 1 for every field k, so depth = 1 < 2 = ν + 1. The Lean statement `conjecture_537_false` is precisely the negation of "every finite bipartite G satisfies matchingNumber G + 1 ≤ depth k G" (for all fields), and `K2_counterexample` gives the witness with all three ingredients.

The depth bound is proved by a neat evaluation-homomorphism argument, which I checked line by line. Let φ, ψ : R → R evaluate y ↦ 0 and x ↦ 0 respectively. If f₁ ∈ m is a nonzerodivisor on M = R/(xy), then u = φ(f₁) ≠ 0 (else f₁ ∈ (y) and f₁x̄ = 0 with x̄ ≠ 0) and ψ(f₁) ≠ 0 by symmetry. From f₁ − u ∈ (y) and u ∈ (x) one gets xu ≡ xf₁ and yu ∈ (xy) modulo (xy), whence m·ū ⊆ f₁M for every m ∈ (x, y). If moreover ū ∈ f₁M, applying φ to u − f₁g = xyh gives u = u·φ(g), so φ(g) = 1; applying ψ gives 0 = ψ(f₁)ψ(g), so ψ(g) = 0; but ψ∘φ = φ∘ψ (both are evaluation at (0,0)) gives 1 = 0, a contradiction. Hence every f₂ ∈ m kills the nonzero class of ū in M/f₁M, so no element of m is a nonzerodivisor on M/f₁M: no m-regular sequence of length 2 exists and depth ≤ 1. (In fact depth = 1, since x + y is a nonzerodivisor — noted in the report, not needed.)

Faithfulness: depth is formalized as the supremum (in ENat) of lengths of Mathlib `IsRegular` sequences from the homogeneous maximal ideal m — the standard depth w.r.t. the irrelevant ideal for these edge ideals; the matching number is the supremum of edge-counts of Mathlib `IsMatching` subgraphs; bipartite is 2-colourability; the edge ideal is generated by x_u x_v over edges; the field ranges over all k. The parenthetical in the conjecture text ("partially known; … the chordal bipartite equality characterization") does not weaken the main clause, which the submission attacks; the report says explicitly that it makes no claim about the parenthetical. The counterexample works over every field, so no field choice rescues the clause; and it applies equally if ν were read as the induced matching number (ir(K₂) = 1 as well).

Sanity check: k[x,y]/(xy) has associated primes (x), (y); x + y lies in neither, so depth ≥ 1; dim = 1 so depth = 1 < 2 ✓. The conjectured inequality fails already at ν = 1.
