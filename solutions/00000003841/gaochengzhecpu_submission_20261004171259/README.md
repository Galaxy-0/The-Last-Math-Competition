# Proof of conjecture 00000003841

Let P_n be the plactic monoid on n >= 1 letters. A real number c has
the property that every finite monoid M receives at most |M|^c
surjective homomorphisms from P_n if and only if c >= n. So a constant
c(n) as in the source exists, the optimal exponent is c(n) = n, it is
at least 1, and it grows without bound.

Upper bound: P_n is generated by the n letters, so there are at most
|M|^n homomorphisms to M. Lower bound: the Knuth relations hold in every
commutative monoid, so every map from the letters to the cyclic group
Z/p extends to a homomorphism, and it is surjective unless it is zero.
This gives p^n - 1 surjective homomorphisms to a monoid with p
elements, and for c < n a large prime p violates the bound p^c.

## Scope and artifacts

SOURCE.md contains the exact bilingual source. main.tex/main.pdf contain
the complete proof. In Lean, the plactic monoid is the quotient of
Mathlib's FreeMonoid (Fin n) by the congruence generated (conGen) by the
two Knuth relations. numSurj n M is the cardinality of the type of
surjective monoid homomorphisms from it to M. IsAdmissible n c says that
numSurj n M is at most (card M)^c for every finite monoid M, with c a
real number and Mathlib's real power. The theorems are

- isAdmissible_iff: for n >= 1, c is admissible if and only if n <= c;
- isLeast_admissible: for n >= 1, n is the least admissible exponent;
- conjecture_true: an admissible exponent exists for every n; for
  n >= 1 a least one exists and is at least 1; and for every real B
  all admissible exponents for all sufficiently large n are at least B.

The whole statement is formalised; nothing in the main theorem is left
to the paper.

Reading and limits. "Optimal exponent" is read as the least admissible
real exponent. The clause on the optimal exponent is proved for n >= 1;
for n = 0 the monoid is trivial, every real number is admissible and no
least one exists. The proof uses only that P_n is generated by n
elements and that the Knuth relations hold in commutative monoids, so
the result is elementary and the same answer holds for the free monoid
and the hypoplactic monoid. The source's label speaks of a "quotient
count"; its statement in both languages counts surjective
homomorphisms, which is what is proved. If one counted them up to
automorphisms of M, the optimal exponent would lie in [n - 1, n], still
unbounded, but it would be 0 for n = 1; that variant is discussed in
the paper and not formalised.
