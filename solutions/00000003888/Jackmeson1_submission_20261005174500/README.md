# Disprove conjecture 00000003888: the HK density function of (k[x,y,z], (x,y,z)) is x²/2 on [0,1), not piecewise linear

- **Claim refuted.** Clause 1: the HK density function of a fixed ideal is piecewise linear with finitely many breakpoints. The conjunction is therefore false; clause 2 (families with unbounded breakpoint counts) is not addressed.
- **Definition.** Trivedi's HK density function (arXiv:1510.03294, retrieved and quoted): HKd(R,I)(x) = lim_n q^{−(d−1)} ℓ(R/I^{[q]})_{⌊xq⌋}, q = p^n, with I^{[q]} generated by q-th powers of elements of I.
- **Witness.** R = k[x,y,z], I = (x,y,z), over any field of characteristic p > 0; I is homogeneous with dim_k R/I = 1, and I^{[q]} = (x^q, y^q, z^q) by Frobenius additivity.
- **Computation.** For m < q every degree-m monomial is standard, so dim (R/I^{[q]})_m = C(m+2, 2) and f_n(x) → x²/2 on [0,1) (consistent with Trivedi's Example 3.1, which the proof does not use). The graded-piece lemma for monomial ideals is reused from our package for 00000000539.
- **Not piecewise linear.** x²/2 is not affine on any subinterval of (0,1), so HKd is not piecewise linear on any domain containing (0,1); the partition form and any pointwise-limit convention are covered.
- **Scope.** The text does not restrict the dimension; the witness has dimension 3. In dimension 2, piecewise linearity is Trivedi's theorem.
- **Main theorem.** `C3888.conjecture_false`.
