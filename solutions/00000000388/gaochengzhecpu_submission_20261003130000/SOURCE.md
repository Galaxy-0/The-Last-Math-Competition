# 00000000388

**English.** Definition: The W_m residual classes consist of numbers whose approximation orders satisfy w_n(ξ) ≤ n/m for infinitely many n but which belong to no U_k. Conjecture: Each W_m is nonempty and uncountable, distinct W_m are disjoint, and the union of the classes is the full set of transcendentals. (Wm residual classes nonempty uncountable)

**中文。** 定义：W_m 余类指逼近阶满足 w_n(ξ)≤n/m 对无穷多 n 但不属任何 U_k 的数。猜想：每个 W_m 非空且不可数且不同 W_m 互不相交；并类的并为全超越集。（Wm 余类非空不可数）
