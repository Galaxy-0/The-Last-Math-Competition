B. COMPLETE MATHEMATICAL ARGUMENT

Let k be any natural number with k >= 2. Set c_k = 1/(2k), a positive real number.
To produce a qualifying integer beyond an arbitrary natural bound N, set

    t = max(2^k, N+k+3).

Thus t>k, t>N, t>=2, and t>=2^k. For each nonnegative integer j, Bertrand's
postulate supplies a prime p_j such that

    2^j t < p_j <= 2^(j+1) t.

These primes are strictly increasing: if i<j, then i+1<=j, so
p_i <= 2^(i+1)t <= 2^j t < p_j. In particular p_0,...,p_(k-1) are distinct
primes and hence pairwise coprime. Every p_j exceeds t, so for j<k it also exceeds
j+1. The natural subtraction p_j-(j+1) is therefore the intended residue.

By the finite Chinese remainder theorem, there is a representative n with

    0 <= n < product_(j=0)^(k-1) p_j
    n congruent to p_j-(j+1) modulo p_j  for every j<k.

Adding j+1 gives p_j | n+(j+1). For j=0, p_0 | n+1 and n+1>0, whence
p_0 <= n+1. Since p_0>t, the natural-number inequalities imply n>=t. Thus n>N
and n>=2; the bounded CRT representative cannot stay small as t grows.

For j<k, its size satisfies

    p_j <= 2^(j+1)t <= 2^k t <= t^2.

Consequently

    n < product_(j=0)^(k-1) p_j <= (t^2)^k = t^(2k).

Since 2k>0 and n,t are nonnegative, monotonicity of positive real powers gives

    n^(1/(2k)) < t < p_j     for every j<k.

For the original offset i in {1,...,k}, take j=i-1. Then p_j is a prime divisor
of n+i. Its actual largest prime divisor P(n+i) is at least p_j, so

    n^c_k < p_j <= P(n+i).

Every offset holds for the SAME n and SAME c_k. Since N was arbitrary, the set
of these n is unbounded in the naturals and therefore infinite. This proves the
full source assertion for every k>=2, with no hypothesis on k beyond that in the
source and no change to the strict real inequality.

The largest-prime-factor meaning is proved separately in Lean. For m>=2,
Nat.primeFactors m is nonempty, every member is prime and divides m, and its
finite supremum is a member dominating every other prime divisor. Hence it is
the actual largest prime factor. The exact threshold equivalence with the
existence of some prime divisor above the same real threshold is also proved.
No numerical search, finite experiment, heuristic estimate, or unproved
asymptotic statement enters this argument.
