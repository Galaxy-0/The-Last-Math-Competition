3. CANONICAL EXPLICIT TARGET

For integers m ≥ 2, write P(m) for the largest prime divisor of m. Its defining
meaning is: P(m) is a natural prime, P(m) divides m, and every natural prime q
which divides m satisfies q ≤ P(m). The multiplicity of a prime factor does not
change P(m). To make this a total function on N in the displayed specification,
set P(0)=P(1)=1 by convention; these two values do not denote actual prime factors
and never enter a qualifying inequality below.

For k,n in the natural numbers and c in the reals, put

    Good(k,c,n) :⇔
      2 ≤ n and
      for every natural i with 1 ≤ i ≤ k,
          (n cast to the reals)^c < (P(n+i) cast to the reals).

The canonical source target is

    C :⇔ for every k in N with 2 ≤ k,
           there exists c in R such that 0 < c and
             {n in N : Good(k,c,n)} is infinite.

Equivalently, with every quantifier explicit:

    for every k in N,
      2 ≤ k implies
        there exists c in R such that
          0 < c and
          for every N in N,
            there exists n in N such that
              N < n and 2 ≤ n and
              for every i in N,
                1 ≤ i implies i ≤ k implies
                  (n cast to R)^c < (P(n+i) cast to R).

Here the power is the ordinary real power on a positive real base. In Lean,
Real.rpow (n : R) c, or notation with explicitly real base and exponent, has this
meaning. It is not natural-number exponentiation, integer division in an
exponent, a floor of the real power, or a power of the prime factor. The same base
n occurs for every i; the stated threshold is not (n+i)^c.

A specification avoiding any totalized P function is also exact: replace the
last inequality for each i by the existence of a natural p satisfying all four
conditions

    p is prime;
    p divides n+i;
    every natural prime q dividing n+i satisfies q ≤ p;
    (n cast to R)^c < (p cast to R).

This p is the actual largest prime divisor, not an arbitrary chosen parameter.
The canonical target is a mathematical specification in this report, not an
unverified declaration that any particular Lean implementation has this type.

4. QUANTIFIER AND SIMULTANEITY GATES

G1 — Full family: every natural k ≥ 2 is quantified. A result for k=2, a finite
list of k, or some unbounded sequence of lengths does not by itself constitute
the exact source theorem without an explicit logical bridge covering every k.

G2 — Uniform exponent within each family member: c may depend on k. It is
chosen before the infinity claim, independently of n, the bound N, and offset i.
The source does not require one c to work for every k, nor a specified formula
or effective procedure for c. It permits any positive real c, with no additional
upper bound stipulated by the source.

G3 — Common n: for each qualifying n, ALL offsets i=1,...,k satisfy the inequality
with that same c and that same n. Separate infinitude statements for individual
offsets do not automatically yield an infinite simultaneous intersection.

G4 — Offset endpoints: n+1 and n+k are both included; n itself is not. A Fin k
encoding must use i+1. A bounded natural quantifier must include both inequalities
1 ≤ i and i ≤ k. Every shift and cast must preserve these exact integers.

G5 — Actual prime factors: any largest-prime representation needs a verified
connection to all prime divisors of n+i. A least prime divisor, arbitrary divisor,
prime power, factor count, number with an imposed name, or maximum of an unrelated
finite set is not an acceptable replacement.

G6 — Strict bound: "exceeds" and ">" mean strict real inequality. Replacing <
with ≤ at the same fixed exponent changes the pointwise predicate. Any altered
bound or exponent domain used internally needs a proved bridge to C; the final
semantic claim must retain the full real-positive-exponent target.

G7 — Ordinary infinitude: the set of qualifying natural n is infinite in the
standard sense. One n, arbitrarily many repeated certificates for one n, or an
infinite indexing type with non-distinct outputs is insufficient. The equivalent
unbounded formulation above forces qualifying n beyond every natural bound.
The source neither demands positive density nor says all sufficiently large n
qualify; neither extra property is part of the required target.

5. BOUNDARY CONVENTIONS AND EXACT REPRESENTATION BRIDGES

B1 — Finite boundary deletion. The conventional choices N={0,1,2,...} or positive
integers, and the exclusion n<2 in Good, differ by only finitely many n. For each
fixed k and c, ordinary infinitude is unchanged by deleting those finitely many
values. Thus restricting to n≥2 is an exact treatment of the source's infinitude
statement, not a substantive weakening. It makes every n+i≥3, so the usual largest
prime divisor exists and the real base is positive. The same reasoning allows
n≥1, for which n+i≥2. No convention at 0 or 1 can manufacture infinitude.

B2 — Totalized largest-prime functions. One may assign arbitrary fixed values to
P(0) and P(1), or use a library finite-set maximum convention, provided agreement
with the actual largest prime divisor is established for every m≥2. Because
Good explicitly has n≥2, those exceptional assignments are never evaluated in
its inequalities. In particular, the set of all prime divisors of 0 must not be
silently regarded as a finite nonempty set with a largest element.

B3 — Prime-factor finite set. P(m) can be represented by the maximum of
Nat.primeFactors m for m≥2. The required semantic bridge is that membership is
exactly primality and divisibility for nonzero m, that the set is nonempty for
m≥2, and that its maximum belongs to it and dominates its members. Use of a
finite supremum with a default value requires this same positive-domain bridge.

B4 — Existential prime divisor threshold. For m≥2 and a real threshold t,

    t < (P(m) cast to R)
      if and only if
    there exists a natural prime p dividing m with t < (p cast to R).

This is an exact semantic equivalence from the defining maximum property.
Consequently, a formulation using some prime divisor above the SAME threshold
can be faithful, even though it does not name the largest divisor. The equivalence
must be supplied in the formal/report correspondence; mere divisibility with no
primality, or no threshold, does not give this equivalence. This bridge makes no
claim that any n meeting the conjecture exists.

B5 — Infinitude/unboundedness. For a subset S of the natural numbers,

    S is infinite iff for every N in N there is n in S with N<n.

This is the exact equivalence used between the two target forms. Bounds written
with ≤ can also express unboundedness when universally quantified, but must not
be confused with a single finite bound. A later implementation should explicitly
justify its chosen standard infinitude representation.

No other semantic surrogate is preapproved. In particular, rational or natural
exponents, a different base, non-strict inequalities, density conclusions,
restricted k-domains, or rearranged quantifiers cannot be called the source
statement just by changing its name. Any internal variant must connect rigorously
to the full canonical target.
