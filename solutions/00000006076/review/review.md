## Semantic audit
The conjecture states that for a strict saddle (negative curvature nondegenerate) the escape window is controlled by the curvature ratio, that escape is deterministic within the window, and that it is exponential. The submission disproves this unqualified deterministic claim with the classical stable-manifold obstruction. On E = ℝ² with f(x,y) = x² − y²: the Hessian is diag(2,−2), invertible, with quadratic form +2 on the first coordinate axis and −2 on the second, so the origin is a nondegenerate strict saddle that is neither a local minimum nor a local maximum; the curvatures have equal magnitude (ratio 1), so no extreme or degenerate curvature data is involved. The gradient is globally 2-Lipschitz and the step η = 1/4 lies in the safe range (0, 1/L) = (0, 1/2). The gradient-descent map is exactly T(x,y) = (x/2, 3y/2).

For any radius r > 0 the start z₀ = (r/2, 0) is nonstationary (∇f(z₀) = (r, 0) ≠ 0) and lies strictly inside B(0,r); the exact orbit zₙ = Tⁿz₀ = (r·2⁻ⁿ⁻¹, 0) satisfies ‖zₙ‖ = r·2⁻ⁿ⁻¹ < r for all n ≥ 0 and converges to the saddle. Hence no positive-radius window — in particular none chosen from the curvature ratio, which here is 1 — makes escape deterministic for its nonstationary starts, and the escape rate cannot be exponential for these trajectories, whose distance to the saddle instead decays exponentially. This violates precisely the conjecture's stated conclusion while satisfying every stated hypothesis, and the negation's quantifier structure (∃ nonstationary start inside every window that never escapes) is exactly right for refuting a universal window guarantee. The report is careful to scope the result: it does not claim anything about perturbed, randomized, or generic-start escape statements, which the official text does not assert.
