## Semantic audit
The classification clause asserts that connected components of the Fredholm domain (norm topology) are completely classified by the pair (index, essential spectrum). Any complete classification by data D requires D to be constant on each component — otherwise two members of one component carry different data and the data cannot determine the component. The submission exhibits exactly such a violation, in the correct logical direction for a refutation (existence of a violating pair): on H = ℓ²(ℕ, ℂ), the operators I and 2I are both Fredholm of index 0, and γ(t) = (1+t)I is a norm-continuous path of invertible (hence Fredholm) operators joining them, so both lie in a single connected component; but σ_ess(aI) = {a} for every scalar a, so σ_ess(I) = {1} ≠ {2} = σ_ess(2I). This is the canonical minimal counterexample to a claim that is classically false — indeed, components of the Fredholm set are classified by the index alone, and the essential spectrum is manifestly not a component invariant. The report honestly scopes the refutation: it does not dispute the (true) index-constancy clause, and one refuted conjunct suffices for the conjunction; the family-index clauses need not be decided.

The formalization is faithful in every definition. `H := lp (fun _ : ℕ => ℂ) 2` is the genuine ℓ² space, proved infinite-dimensional through the standard Hilbert basis (`HilbertBasis.ofRepr` of the defining linear isometry equivalence). `Fredholm A` is the complete standard predicate — closed range (`IsClosed (Set.range A)`), finite-dimensional kernel, finite-dimensional quotient H ⧸ range — and `index` is dim ker − dim cokernel as an integer. `essentialSpectrum A = {z | ¬ Fredholm (A - z • 1)}` is precisely the Fredholm essential spectrum of the report. For a ≠ 0, `scalar a` is injective and surjective with kernel ⊥ and range ⊤, hence Fredholm with index 0; `zero_not_fredholm` uses the infinite dimensionality (kernel of 0 is all of H); `essential_scalar` then derives σ_ess(aI) = {a} by a clean dichotomy. `joiningPath` is a genuine `Path` in the subtype `{A : Op // Fredholm A}` with the norm subspace topology, with continuity from scalar multiplication; `same_component` transports it via `pathComponent_subset_component`.
