## Semantic audit
The conjecture's universality clause asserts a positive constant c with α_K ≥ c/ratio(K) for all convex bodies. To refute it, one must exhibit, for every c > 0, a convex body violating the bound — equivalently one body with α_K·ratio(K) = 0. The submission takes dimension one, which neither the English ("for all convex bodies") nor the Chinese ("对一切凸体成立") text excludes, and which is squarely within this competition's established literal-reading methodology. In dimension one every notion in the conjecture is meaningful: K = [-1,1] is a compact convex set with nonempty interior; its boundary is {-1,1}; the intrinsic surface measure is 0-dimensional Hausdorff measure restricted to the boundary, which equals δ_{-1} + δ_1 (each singleton has H⁰-measure 1, and additivity on the disjoint endpoints applies); σ_K = ½(δ_{-1}+δ_1) is the normalized boundary probability; the surface-to-volume ratio is H⁰(∂K)/|K| = 2/2 = 1.

With the standard rate convention α·Ent_σ(q²) ≤ 2∫|∇q|²dσ, the admissible set is {α ≥ 0 : the inequality holds for all smooth q}, and α_K is its supremum. The test function P(x) = (2+3x-x³)/4 is a polynomial with boundary values P(-1) = 0, P(1) = 1 and derivative P'(x) = (3-3x²)/4 vanishing at both endpoints. Its energy is ½(|P'(-1)|²+|P'(1)|²) = 0, while ∫P²dσ = ½ and ∫P²log P² dσ = 0·log 0 + 1·log 1 = 0 under the 0log0 = 0 convention, giving Ent_σ(P²) = ½ log 2 > 0. Any α > 0 would demand α·(½ log 2) ≤ 0, impossible; zero is trivially admissible. Hence the admissible set is exactly {0} and α_K = 0, so α_K·ratio(K) = 0 and no positive universal c exists. Convention-robustness: the Lean energy uses the ambient gradient, which dominates the tangential (projected) gradient; since P's ambient gradient vanishes at both boundary points, its tangential gradient vanishes a fortiori (indeed in dimension one the tangent spaces are zero-dimensional and every tangential gradient is zero, making α_K = 0 for every interval under the intrinsic convention as well). The report explicitly and honestly scopes the result: it does not claim anything about versions restricted to n ≥ 2, nor about the curvature-approximation or prism clauses — unnecessary, since one refuted conjunct refutes the conjunction.

The formalization matches this outline declaration by declaration: real H⁰ via `Measure.hausdorffMeasure 0` restricted to `frontier K` and computed as a sum of Diracs; `sigma` normalized to a probability (`IsProbabilityMeasure` instance); `surfaceVolumeRatio` as the toReal quotient of surface mass and Lebesgue volume (`Real.volume_Icc`), proved equal to 1; `integral_sigma` reducing σ-integrals to endpoint averages; `entropy` and `energy` as genuine Bochner integrals; `Admissible a := 0 ≤ a ∧ ∀ q, ContDiff ℝ ⊤ q → a * entropy q ≤ 2 * energy q`; `admissible_set = {0}`; `optimalConstant = sSup {a | Admissible a} = 0`; and `lower_bound_fails (c) (hc : 0 < c) : ¬ c / surfaceVolumeRatio ≤ optimalConstant` — precisely the negation of the conjectured inequality for this body. Since the conjecture posits a universal positive c, this single body with α_K·ratio = 0 falsifies it. Entropy of P is computed from the actual integrals (`norm_num` after `integral_sigma`, using Real.log's standard log 0 = 0 extension implementing 0log0 = 0), not by assigning values.
