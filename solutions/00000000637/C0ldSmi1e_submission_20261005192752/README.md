# Conjecture 00000000637: disproof of the literal full-twist-square claim

At three strands, the full twist `T = (ab)^3 = (aba)^2` is a central pure braid outside the subgroup generated by `T^2`. The ordinary exponent homomorphism has value 6 on `T` and value `12k` on `(T^2)^k`, for every integer `k`. This refutes the necessary center conjunct at the allowed value `n = 3`, hence the entire conjunction in the original statement.

The source says **square of the full twist** in both languages. This submission preserves that wording: it does not replace the full twist by the half twist. The arbitrary proposition in the last Lean theorem expresses conjunction logic; it is not a definition of stable commutator length and makes no separate scl claim. The report states the source's scl-domain/uniformity ambiguity and explains why this counterexample is independent of it.

## Reproduce the proof

Use Python 3.11 or newer, Git, and an installed Lean/Elan toolchain. All commands below start in this submission directory unless a `cd` is shown.

```sh
cd lean
lake exe cache get
lake build
python3 verify.py
lake env lean -DwarningAsError=true Check.lean
cd ..
```

The checked-in manifest pins all nine packages. Keep it unchanged when obtaining dependencies. The replay tools verify every pinned dependency revision and require clean tracked dependency sources. `lake exe cache get` retrieves standard Mathlib build products; this does not substitute for rebuilding the submitted source. For environments with the exact packages already provisioned, omit dependency setup.

The project pins Lean 4.19.0 (compiler commit `6caaee842e9495688c1567e78c0e68dbb96942aa`) and Mathlib v4.19.0 (commit `c44e0c8ee63ca166450922a373c7409c5d26b00b`). The author tool is located next to the project and writes new `verification.json` and `verification-logs/` there, preserving the historical records under `verification/`.

For the broader independent run, choose build/evidence directories that do not yet exist:

```sh
python3 tools/independent-verify.py --ready \
  --source "$PWD/lean" \
  --build-dir /tmp/tlmc637-my-fresh-build \
  --evidence-dir /tmp/tlmc637-my-fresh-evidence \
  --lean-bin "$(dirname "$(cd lean && elan which lean)")" \
  --packages "$PWD/lean/.lake/packages" \
  --audit-names "$PWD/verification/inputs/audit-names.json" \
  --frozen-sources "$PWD/verification/inputs/frozen-sources.json"
```

The independent inspector copies all three project Lean modules and all three configuration files to the new build directory. It verifies frozen hashes, pins and toolchain, performs the entire Lake build, directly replays every module with `-DwarningAsError=true`, checks all handwritten declaration coverage, inventories every compiled constant from the implementation modules, checks transitive logical dependencies, and rechecks source/tool/dependency identities afterward. Its generated metaprogramming harness is inspection code only and proves no mathematical theorem. Historical inspection harnesses under `verification/` are evidence, not part of the project's import graph.
