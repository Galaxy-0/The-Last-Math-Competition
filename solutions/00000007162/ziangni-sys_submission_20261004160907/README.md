# Disproof of conjecture 00000007162

The nonconstant convex spectral function f(M)=(tr M)² on all real 2×2 matrices has the nonnormal Jordan nilpotent as a genuine Fréchet-critical point. Spectral means dependence on eigenvalues with multiplicity, formalized by dependence on the actual characteristic polynomial and invariance under all invertible conjugations.

The report explicitly distinguishes the unrestricted matrix domain from a Hermitian-only domain or singular-value functions. The source states neither restriction.
