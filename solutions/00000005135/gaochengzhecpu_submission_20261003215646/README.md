# Conjecture 00000005135: Disproof

With the standard common perturbation norm, structured Hankel perturbations form a subset of the unstructured perturbations. Their condition number is therefore no larger than the unstructured condition number. Every finite, defined structured/unstructured ratio, and every supremum of such ratios, is at most 1, so the claimed endpoint sqrt(4) = 2 cannot be attained.

## Scope

The result uses the ratio direction stated in the source, the same ambient perturbation norm and amplification function, and a positive finite denominator. It refutes the claimed upper-endpoint assertion under that standard interpretation. Undefined ratios and comparisons using differently scaled norms are outside the statement proved.
