# Counterexample to conjecture 00000003824

The conjecture says that the Nakajima monomial crystal `M(λ)` decomposes into connected
components `⊕ B(μ)`, where `μ` runs exactly over the dominant integral weights `μ ≤ λ` in
dominance order, each appearing exactly once. This is false already for `sl₂` and `λ = 2`.

For `sl₂` the dominant `μ ≤ 2` are `μ ∈ {2, 0}`, so the claim predicts `M(2) ≅ B(2) ⊕ B(0)`
(4 vertices, with a highest-weight vertex of weight 0). In Kashiwara's realization of Nakajima's
monomial crystal (monomials in `Y_m`, `m ∈ ℤ`, `A_m = Y_m Y_{m+1}`), the crystal generated by the
highest-weight monomial `Y₀²` is

| `M` | wt | φ | ε | `f̃ M` | `ẽ M` |
|---|---|---|---|---|---|
| `Y₀²` | 2 | 2 | 0 | `Y₀Y₁⁻¹` | 0 |
| `Y₀Y₁⁻¹` | 0 | 1 | 1 | `Y₁⁻²` | `Y₀²` |
| `Y₁⁻²` | −2 | 0 | 2 | 0 | `Y₀Y₁⁻¹` |

So `M(2) = {Y₀², Y₀Y₁⁻¹, Y₁⁻²} ≅ B(2)`. It has 3 vertices and no highest-weight vertex of
weight 0, so it is not `B(2) ⊕ B(0)`. In general `M(λ) = {Y₀^{λ−k} Y₁^{−k}} ≅ B(λ)` (the
`sl₂` case of Kashiwara's theorem), so the claim fails for every `λ ≥ 2`. It holds only for
`λ ∈ {0, 1}`.

Other readings of "M(λ)" are also covered:

- **(U)**: the union of the crystals generated by *all* highest-weight monomials of weight `λ`.
  This fails for every `λ`, since `Y₀^λ` and `Y₁^λ` give two copies of `B(λ)`.
- **(P)**: the crystal generated by products of `λ` fundamental monomials, which realizes
  `B(1)^{⊗λ}`. Here `λ = 2` is true, but `λ = 3` gives `B(3) ⊕ B(1) ⊕ B(1)`, so `B(1)` appears twice.

- **Dominance without parity** (plain `μ ≤ λ`, e.g. `μ ∈ {0,1,2}` for `λ = 2`): the claim still
  fails, because `B(λ−1)` (and `B(λ−2)`) is missing (`main_fails_all'`, every `λ ≥ 1`).
- **KR reading**: in `sl₂` KR modules are irreducible. The KR highest-weight monomial `Y₀Y₁`
  generates `{Y₀Y₁, Y₀Y₂⁻¹, Y₁⁻¹Y₂⁻¹} ≅ B(2)`, which agrees with the main reading (`kr2_fails`).

`λ = 3` defeats the main reading, (U) and (P) at once.

## Contents

- `lean4/`: a self-contained Lean 4.19.0 project (core library only, no Mathlib).
- `verify.py` (Python 3 standard library) checks the following:
  - `M(λ)` is a single string `B(λ)` for `λ ≤ 8` in two index conventions. Here φ, ε, n_f and
    n_e are computed by brute force over a window of integers.
  - Reading (U), by enumerating highest-weight monomials.
  - Reading (P), against the Clebsch–Gordan multiplicities for `λ ≤ 5`.
  - `sl₃`: `|M(ϖ₁+ϖ₂)| = 8`, but `B(θ) ⊕ B(0)` would have 9 vertices.
- `verification.txt`: the fresh build log, forbidden-token scan, axiom audit and Python output.

## Lean

- `Mon` represents a monomial as a canonical list of `(index, exponent)` pairs.
  - `wt`, `phi` and `eps` follow Kashiwara's formulas `φ = max_n Σ_{k≤n} y_k` and
    `ε = max_n (−Σ_{k>n} y_k)`.
  - `fT` and `eT` are `f̃` and `ẽ`, with `n_f` the minimal and `n_e` the maximal index
    attaining the maximum.
- `Reach s x` says that `x` is generated from `s` by `f̃` and `ẽ`. `Mmain l = Reach (Y0pow l)`
  is `M(λ)`.
- `Target l` together with `wtB`, `fB` and `eB` is `⊕_{μ dominant, μ ≤ λ} B(μ)`, with one copy of
  each `B(μ)`. `CrystalIso` is a bijection that preserves weights and both arrows.
  `Decomposes V l` says that `V ≅ Target l`.
- Main results:
  - `M2_eq` shows that `M(2)` is exactly the three monomials, and `iso_M2_B2` shows `M(2) ≅ B(2)`.
  - `conjecture_00000003824_clause_false : ¬ Decomposes (Mmain 2) 2`, and
    `conjecture_00000003824_false : ¬ Conjecture`.
  - `main_fails_all`: the clause fails for every `λ ≥ 2`. This is a symbolic proof, not a
    finite check.
  - `main_fails_all'` covers dominance without parity, and `kr2_fails` covers the KR reading.
  - `union_fails` covers every `λ`, `prod3_fails` covers reading (P), and
    `all_readings_fail_at_3` covers all three readings at `λ = 3`.
- Non-vacuity: `main_holds_0`, `main_holds_1` and `prod_holds_2` construct explicit
  isomorphisms. `sanity` checks the canonical form, `φ − ε = wt`, and that `f̃` and `ẽ` are
  mutually inverse on every component used.

The project has no `sorry`, no `native_decide` and no added axioms. `#print axioms` lists only
`propext` and `Quot.sound`. `Classical.choice` also appears for `main_fails_all`, `main_fails_all'`
and `all_readings_fail_at_3`.

Scope: the Lean development covers `sl₂` only.
- Kashiwara's general theorem (`M(λ) ≅ B(λ)` in all types) is cited, not formalized.
- The crystal axiom `f̃ M = M' ⟺ ẽ M' = M` is checked on the components used. It is not proved
  for all monomials.
- The `sl₂` window counts for (U) and the `sl₃` example come from `verify.py` only.

## 中文说明

猜想声称 Nakajima 单项式晶体 M(λ) 的连通分量分解为 ⊕B(μ)，其中 μ 恰取遍支配序下不超过 λ 的支配整权，且每个恰好出现一次。
这在 sl₂、λ = 2 时就不成立。此时不超过 2 的支配权为 μ ∈ {2, 0}，猜想预言 M(2) ≅ B(2) ⊕ B(0)，共 4 个顶点。
但在 Kashiwara 对 Nakajima 单项式晶体的实现中（变元 Y_m，A_m = Y_m Y_{m+1}），由最高权单项式 Y₀² 生成的晶体只有三个元素：
Y₀²、Y₀Y₁⁻¹、Y₁⁻²。它同构于 B(2)，没有权为 0 的最高权顶点，因此不同构于 B(2) ⊕ B(0)。
一般地，M(λ) = {Y₀^{λ−k}Y₁^{−k}} ≅ B(λ)，所以对每个 λ ≥ 2 猜想都不成立。
我们还讨论了两种其他读法：
- (U) 取所有权为 λ 的最高权单项式生成的晶体之并：对每个 λ 都不成立，因为 Y₀^λ 与 Y₁^λ 给出两个 B(λ)。
- (P) 取 λ 个基本单项式之积生成的晶体，即 B(1) 的 λ 次张量幂：λ = 2 时成立，但 λ = 3 时 B(1) 出现两次。

若把"不超过 λ"理解为不带奇偶条件的 μ ≤ λ，猜想同样不成立，因为缺少 B(λ−1)。
KR 模读法：sl₂ 的 KR 模不可约，其最高权单项式 Y₀Y₁ 只生成 B(2)，与主读法一致。
λ = 3 同时否定主读法、(U) 和 (P)。我们用 Lean 4（仅核心库）对 sl₂ 形式化了单项式晶体、Kashiwara 算子、生成子晶体、B(μ) 以及晶体同构，
并证明了 ¬Conjecture、对所有 λ ≥ 2 的反例，以及上述各种读法下的反例。verify.py 用独立方法复核了上述结论。
