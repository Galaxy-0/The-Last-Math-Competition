## Semantic audit
Literal claim (EN/CN agree): "for fixed t ≥ 3 there are only FINITELY many isomorphism classes of designs whose automorphism group is t-transitive" (固定 t ≥ 3 …仅有有限个同构类). The submission fixes t = 3 and exhibits, for every v ≥ 5 (Lean: every n : ℕ with v = n+5), the design of all (v−1)-subsets: a 3-(v, v−1, v−3) design whose full automorphism group is S_v (3-transitive), with distinct v giving nonisomorphic designs — an infinite set of isomorphism classes, contradicting finiteness. Lean encodings are faithful to the conjecture's own definition:
- `def block (n) (i) := Finset.univ.erase i`, `def blocks n := Finset.univ.image (block n)` — actual complements-of-points block family; `block_injective` proves simplicity, `block_card`/`number_of_blocks` the sizes (k = n+4 = v−1, b = v).
- `def IsThreeDesign (n) : Prop := (∀ B ∈ blocks n, B.card = n + 4) ∧ ∀ T, T.card = 3 → ((blocks n).filter (fun B => T ⊆ B)).card = n + 2` — the conjecture's literal "every t-element subset in exactly λ blocks" incidence condition, proved as `actual_design` via `incidence_count` (blocks containing T ↔ omitted points outside T; count = |Tᶜ| = v−3 = λ). Not a parameter assertion.
- `def IsAutomorphism (n) (e : Equiv.Perm (Point n)) : Prop := ∀ B, B ∈ blocks n ↔ B.image e ∈ blocks n` — actual block-preservation; `permutation_preserves` proves EVERY permutation is an automorphism (so Aut = S_v).
- `def IsThreeTransitive (n) : Prop := ∀ a b : Fin 3 ↪ Point n, ∃ e : Equiv.Perm (Point n), IsAutomorphism n e ∧ ∀ i, e (a i) = b i` — 3-transitivity on ordered triples of distinct points (embeddings Fin 3), proved constructively by extending the range bijection (`three_transitive`).
- `def Isomorphic n m := ∃ e : Point n ≃ Point m, ∀ B, B ∈ blocks n ↔ B.image e ∈ blocks m` with `isomorphic_iff : Isomorphic n m ↔ n = m` (point-bijection cardinality), and `infinitely_many_isomorphism_classes : Infinite (Quotient designSetoid)` via an injective ℕ → Quotient map — a formally infinite quotient by the actual isomorphism relation.
- Final: `theorem conjecture_00000008411 : (∀ n, IsThreeDesign n ∧ IsThreeTransitive n ∧ 3 < n + 4 ∧ n + 4 < n + 5) ∧ Infinite (Quotient designSetoid)` — includes designs, 3-transitivity, and strict 3 < k < v for every member.
Contradiction: infinitely many pairwise nonisomorphic 3-designs with 3-transitive automorphism groups at fixed t = 3 vs. "only finitely many isomorphism classes". Not vacuous — all components are positive constructions/infinite objects. Hypotheses: t = 3 ≥ 3 as required; only t is fixed in the claim (v, k, λ vary), which the report argues explicitly. NOTE (flagged below): the family consists of COMPLETE designs (all (v−1)-subsets), often called trivial in classification terminology — the conjecture text contains NO nontriviality restriction (no "k < v−1", no "proper/noncomplete design"), so under the literal-statement-is-authoritative precedent the counterexample is admissible; the submission is fully transparent about this. Additional note: the conjecture is internally strained anyway — its own classification table includes projective space designs, an infinite family, alongside the finiteness clause; and even under a hypothetical noncomplete restriction, the Steiner quadruple systems SQS(2^d) (d ≥ 3) are an infinite family of non-complete 3-(2^d,4,1) designs with 3-transitive automorphism group AGL(d,2), so the finiteness clause fails in spirit as well (this latter observation is mine, not the submission's, and is not needed for the verdict).
