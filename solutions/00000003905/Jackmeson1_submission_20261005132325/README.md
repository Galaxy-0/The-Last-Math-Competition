# Disprove conjecture 00000003905: μ((x)^{[p^e]}) = 1 in k[x,y], so the degree is not dim R − ht I

- **Counterexample.** R = k[x,y] with k any field of characteristic p, and I = (x): dim R = 2 and ht I = 1, so the predicted degree is 1.
- **Frobenius power.** I^{[q]} is defined as the ideal generated by q-th powers; for q = p^e it is proved to be the same for every generating set.
- **Computation.** Using Mathlib's `Submodule.spanFinrank`, `ringKrullDim` and `Ideal.height`: dim k[x,y] = 2, ht (x) = 1, and μ((x)^{[p^e]}) = 1 for every e (`frobenius_mu_polynomial_is_one`).
- **Conclusion.** Any polynomial P with μ = P(p^e) for all large e is the constant 1, so deg P = 0 ≠ 1 (`conjecture_3905_false`).
- **Not refuted.** Polynomiality alone, the leading-coefficient clause, and ideals of height dim R.
- **Lean.** Lean 4.33.1, Mathlib v4.33.1, 151 lines. Axioms: only `propext`, `Classical.choice`, `Quot.sound`. No `sorry`, no `native_decide`.

**Previous submission and its error (README rule 2).** orionsheep submitted this conjecture in PR #286, which was closed without merging. The reviewer's reason: "The main theorem conjecture_refuted is the vacuous conjunction (2:Nat) = 2 ∧ … ∧ (2*2−2 = 2) ∧ (1 ≠ 0): no ring, ideal, Frobenius power, minimal-generator function μ, or polynomial is defined anywhere in Lean". The reviewer asked for "a version that defines μ on ideals in Lean". This submission defines the Frobenius power I^{[q]} in Lean as the ideal generated by q-th powers. It proves that in characteristic p this ideal is the same for every generating set. It uses Mathlib's minimal number of generators (`Submodule.spanFinrank`), `ringKrullDim` and `Ideal.height`. It proves dim k[x,y] = 2, ht (x) = 1 and μ((x)^{[p^e]}) = 1 for every e, for any field k of characteristic p. It then proves that every polynomial P with μ((x)^{[p^e]}) = P(p^e) for all large e is the constant 1, so deg P = 0 ≠ dim R − ht I = 1.
