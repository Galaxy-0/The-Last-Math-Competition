## Semantic audit
The refutation is clean and decisive: the conjecture's first clause asserts the maximum **is** 660 and **is attained**, which entails the existence of an MDS [12,6] ternary code. But no such code exists: an MDS [12,6]₃ code would be a [12,6,7]₃ code, and the submission proves the q = 3 case of the classical MDS length bound (n ≤ q + k − 1, here n ≤ k + 2) completely elementarily: a linear-dependence lemma gives a nonzero word u of the code vanishing on the first k−2 coordinates; a second application with an augmented column gives an independent word v vanishing there too with disjoint "leading" coefficient; then all 8 nonzero combinations au+bv must have weight ≥ n−k+1, while the coordinate-wise count N(x,y) = 6 (kernel of a nonzero linear form on F₃² has 3 elements) gives total ≤ 6(n−k+2), whence 8(n−k+1) ≤ 6(n−k+2), i.e. n ≤ k+2. I checked every step; it is correct, and it is formalized in Lean symbolically for all n, k (`no_mds_ternary`), not by enumeration. At (n,k) = (12,6) and (12,7) the bound is violated, so no MDS code of either reading of "[12,6]" exists, and the "attained 660" conjunct fails. Since the conjecture is a conjunction whose first conjunct fails, it is false; the remaining clauses about "all other equivalence classes" are vacuous, and the submission correctly makes no claim about them.

The Lean `Conjecture1090` encodes the three-part claim faithfully (`∃ G, IsMDS 12 6 G ∧ PAutOrder 12 6 G 660` first), and `conjecture_00000001090_false` refutes it; variants cover MAut, arbitrary readings (`no_mds_12_6_with` for any property P). The reading analysis is exemplary: the emptiness argument is independent of the notion of automorphism group; both the [n,k] and [n,d] readings of the type are covered; and the two readings under which codes DO exist are separately refuted with real mathematics: (i) the Golay reading [12,6,6] — the monomial class of the extended ternary Golay code splits into exactly five permutation classes with |PAut| = 108, 120, 432, 660, 7920 (verify.py's complete M₁₂ computation, orbit sizes summing to 2¹¹), so the maximum is 7920 = |M₁₁| ≠ 660 and 108, 120, 432 do not divide 132; Lean independently exhibits 720 distinct permutation automorphisms of `golay'` (> 660) via a 30 × 24 product construction with distinctness proved; (ii) with "MDS" dropped, the repeated-pairs code has ≥ 768 (exactly 46080) permutation automorphisms. Non-vacuity is demonstrated (the tetracode is a genuine MDS code in the admissible range; the Golay code is a real [12,6] code with d = 6, one short of MDS).
