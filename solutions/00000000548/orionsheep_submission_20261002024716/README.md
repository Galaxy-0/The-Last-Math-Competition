# Disproof of TLMC Conjecture 00000000548

## Verdict: FALSE

**Conjecture (00000000548).** For a monomial ideal `I`, the minimal number
`ι(I)` of components in an irredundant irreducible decomposition satisfies
`ι(I) ≤ β₀(I)`, where `β₀(I)` is the minimal number of monomial generators
(0-th Betti number). The statement further claims the combinatorial control
is "verified up to n = 12 for monomial ideals" and that "tightness is attained
by complete intersections".

## Attack

In `k[x,y,z]` take the principal monomial ideal

```
I = (xyz).
```

* **Decomposition.** `(xyz) = (x) ∩ (y) ∩ (z)`. Membership on both sides is
  the componentwise condition `e ≥ (1,1,1)`, so the two ideals coincide.
* **Components are irreducible.** Each `(x)`, `(y)`, `(z)` is generated by a
  pure power of a single variable, hence irreducible. Constructively: if `P`,
  `Q` are monomial ideals strictly containing `(x)`, pick monomials `u ∈ P`,
  `v ∈ Q` with exponent of `x` equal to 0; then `u·v` lies in both `P` and
  `Q`, still has `x`-exponent 0, hence lies outside `(x)` — so `P ∩ Q ≠ (x)`.
* **Irredundant.** Removing `(x)` leaves `(y) ∩ (z) ∋ yz = (0,1,1) ∉ (xyz)`;
  similarly `xz` and `xy` witness the necessity of `(y)` and `(z)`.
* **`ι((xyz)) = 3`.** Irreducible monomial ideals are exactly the
  pure-power-generated ones. Exhaustive enumeration (reproduce.py, check5)
  shows that no 1-component or 2-component irreducible-form decomposition of
  `(xyz)` exists inside the box `[0,4]^3`, while the 3-component one does.
  Hence the minimal number of components is exactly 3.
* **`β₀((xyz)) = 1`.** The ideal is principal with minimal monomial generator
  set `{xyz}` (brute-forced in reproduce.py, check3), and it is not the zero
  ideal, so the minimal number of generators is exactly 1.

Therefore

```
ι((xyz)) = 3 > 1 = β₀((xyz)),
```

which refutes `ι(I) ≤ β₀(I)`. The conjecture is **FALSE**.

Note the attack lands inside the claimed "verified up to n = 12" range
(n = 3), and `(xyz)` is itself a complete intersection (one generator), so the
"tightness attained by complete intersections" rider fails as well.

## Boundary and scope

* For any squarefree principal monomial `(x₁x₂⋯x_t)` one has
  `ι = t` and `β₀ = 1`; the inequality fails for every `t ≥ 2` and the ratio
  `ι/β₀` is unbounded already over principal ideals. No bound of the form
  `ι ≤ β₀` can hold on any class containing these.
* The classical correct picture: irreducible monomial ideals are exactly the
  ideals generated by pure powers of variables, and for a principal monomial
  ideal `(m)` the irredundant irreducible decomposition is
  `(m) = ⋂_{x_i ∈ supp(m)} (x_i^{a_i})` with `|supp(m)|` components — here
  `supp(xyz) = {x,y,z}`, giving 3. `ι(I)` equals the number of maximal
  standard pairs of `I`, which is not controlled by the number of generators.
* What the conjecture may have intended: `ι(I) ≤` (number of variables) is
  true for principal squarefree ideals, or bounds of `ι(I)` in terms of other
  invariants (e.g. the number of facets of the Stanley–Reisner complex).
  Repairing the statement is outside the scope of this disproof.

## Verification

* `reproduce.py` — independent recomputation, standard library only
  (`python3 reproduce.py`, about a second). All five checks print `True`;
  recomputed `ι = 3`, `β₀ = 1`, matching the queue/verdict attack numbers
  `ι = 3 > β₀ = 1` exactly.
* `lean4/` — zero-axiom Lean 4 formalization (no Mathlib):
  `cd lean4 && lake build && lake env lean Check.lean`. Every theorem prints
  "does not depend on any axioms"; there is no `sorry` and no classical axiom.
  `main` packages the decomposition, irredundancy, irreducibility,
  `β₀ = 1` and the numeric conclusion `3 > 1`.
* `main.pdf` — exposition of the counterexample with full proofs.
