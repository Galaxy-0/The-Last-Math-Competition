## Semantic audit
The refuted clause is an "if and only if" asserting that the length spectrum of binary linear quasi-perfect codes is {2^k − 1} plus a finite exceptional set. The truth is the opposite extreme: the spectrum is all n ≥ 2, whose complement in ℕ is the finite set {0, 1}. The submission establishes this with three standard families: the even-weight codes (d = 2, e = 0, ρ = 1) for every n ≥ 2; the once-shortened Hamming codes SH(n) = ker(σ) with labels 1..n, proved for all n ≥ 3 with n+1 not a power of two to have d = 3 (no weight-1 word since labels are nonzero, no weight-2 word since distinct labels have nonzero XOR, weight-3 word e₁+e₂+e₃ since 1⊕2⊕3 = 0) and covering radius exactly 2 (every syndrome below 2^{k+1} is 0, a label, or t⊕b with b < t, giving a word of weight ≤ 2 at matching syndrome; the syndrome 2t−1 > n forces distance ≥ 2) — I re-verified all of this by explicit brute force; and the extended Hamming codes (d = 4, ρ = 2) at lengths 2^m. Since the even lengths n ≥ 4 alone form an infinite set disjoint from {2^k − 1}, the "only if" direction of the clause fails for every finite list L (take n = 2(max L + 2)). The Lean encoding `LevenshteinClause := ∃ L : List Nat, ∀ n, QPLen n ↔ ((∃ k, n + 1 = 2^k) ∨ n ∈ L)` is exactly the official clause, and `conjecture_00000007964_false` refutes it, with `QP_spectrum : QPLen n ↔ 2 ≤ n` the exact truth.

The reading analysis is thorough and honest: the conjecture's own stronger definition ("tight uniform shell distribution at covering radius r+1") is formalized as shell-uniformity (equal |S_j(x)| for all j whenever d(x,C) = d(y,C)), the even-weight family is proved shell-uniform for all n in Lean (explicit shell bijections), so the clause is refuted under the conjecture's own notion too (`conjecture_00000007964_false_uniform`); `SH5_not_shellUniform` shows the uniformity condition is a genuine restriction; nontriviality demands (d ≥ 3 via SH(n), d ≥ 4 via EH(m), or any bound D ≤ 4), the non-strict reading (ρ ≤ e+1), and restrictions on k are all covered by named variants; the undefined first conjunct ("gap constant") is explicitly set aside, which is legitimate since refuting one conjunct refutes the conjunction. The report also correctly diagnoses the likely source of the conjecture: the true "finite exceptional list" statement belongs to perfect codes (lengths {2^k−1} ∪ {23}, the Golay exception), not quasi-perfect ones. Non-vacuity is proved in Lean (`hamming_not_QP`: the perfect Hamming codes have ρ = e and are not quasi-perfect; `no_QP_short`: no codes for n ≤ 1).
