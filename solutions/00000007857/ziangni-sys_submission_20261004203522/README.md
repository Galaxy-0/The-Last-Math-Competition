# Counterexample to 00000007857

The displayed scale contains N p^{-1} = N/p. At p=1 the genuine Erdos-Renyi graph is K_N almost surely, with independent Bernoulli(1) edge indicators. Its normalized Laplacian gap is N/(N-1) <= 2 and its lazy-walk gap is N/(2(N-1)) <= 1, but the displayed comparison scale is at least N. No positive eventual Theta lower constant can exist. The dense-regime hypothesis holds because log N/N tends to zero.

Both language versions display the same term. This submission refutes the formula as written, not a modified formula with (Np)^{-1}. It handles both normalized-Laplacian and lazy-walk conventions and does not rely on any assumed value of the second adjacency eigenvalue. The separate concentration and GOE assertions are unnecessary.

Lean constructs actual complete SimpleGraphs and adjacency matrices, computes all positive eigenvalues of the scaled normalized Laplacian, and defines the gap as their actual infimum. It verifies the lazy transition matrix has nonnegative entries and row sums one. The probability model has genuine mutual independence and actual PMF.bernoulli(1) marginal measures for all unordered edges. The full eventual lower-bound obstruction is proved uniformly for every possible second-eigenvalue sequence.
