## Semantic audit
The official conjecture (both language versions) asserts that the general term of a nondegenerate linear recurrence satisfies ‖α_n‖ > n^{−C} for an explicit C, with C determined by the gap between characteristic-root moduli. The submission formalizes the natural universal reading — `ClaimedLowerBound : ∀ (R : LinearRecurrence ℝ) (u : ℕ → ℝ), 0 < R.order → IsMinimalRecurrence R u → Nondegenerate R → HasPolynomialLowerBound u` — and proves its negation. Two features make the reading faithful and the refutation robust. First, `HasPolynomialLowerBound` is the *eventual* form (∃C ∃N ∀n≥N, n>0 → n^{−C} < dist), which is strictly weaker than the pointwise bound stated in the source; refuting the weaker eventual form automatically refutes the pointwise one, so the disproof does not attack a strengthened strawman. Second, the hypotheses are if anything stricter than the official ones: `0 < R.order` is an extra assumption, `IsMinimalRecurrence` ties R to the sequence's true minimal order (so `Nondegenerate R` — the standard condition that all complex characteristic roots are nonzero and no quotient of two distinct roots is a root of unity, via `IsOfFinOrder` — speaks about the sequence's actual characteristic roots), and the counterexample is verified to satisfy all of them.

The mathematics is correct and elementary, and I reverified every identity with exact rational arithmetic. u_n = 2^n + (1/3)^n satisfies u_{n+2} = (7/3)u_{n+1} − (2/3)u_n with charpoly (X−2)(X−1/3); minimality of order 2 follows because an order-1 recurrence would force u_0u_2 = u_1², but u_0u_2 − u_1² = 2·(37/9) − 49/9 = 25/9 ≠ 0 (the Lean proof derives (r−2)² = 0, equivalent). Nondegeneracy holds since quotients 6 and 1/6 are not roots of unity; note the two root moduli even have the fixed positive gap 5/3, so the example sits squarely inside the regime the conjecture purports to control. Since 0 < 3^{−n} ≤ 1/3 < 1/2, the nearest integer to u_n is 2^n and ‖u_n‖ = 3^{−n} exactly (proved in Lean via `round`, `distanceToIntegers_eq_round`); no positive-index term is an integer, and u_n → ∞. As n^C·3^{−n} = n^C e^{−n log 3} → 0 for every real C (Lean: `polynomial_mul_third_pow_tendsto` from `tendsto_rpow_mul_exp_neg_mul_atTop_nhds_zero`), the inequality ‖u_n‖ > n^{−C} fails on a full tail for every C — killing both the "explicit C" clause and any root-gap-determined rule for C, since no C works at all.

The supplemental example v_n = 2^n + 3^n (v_{n+2} = 5v_{n+1} − 6v_n, integer coefficients, integer initial data, v_0v_2 − v_1² = 1 ≠ 0, roots 2 and 3 with quotients 2/3, 3/2 not roots of unity) has every term an integer, so ‖v_n‖ = 0 < n^{−C} at every positive index. This forecloses the one escape route a skeptic might invoke — reading "linear recurrence" as integer-coefficient with integer initial data — under which the main rational-coefficient example would be inadmissible. The report honestly discusses the convention issue, cites the standard nondegeneracy definition (D'Costa–Ouaknine–Worrell, STACS 2024), and does not overstate: both `conjecture_false` (main example) and `conjecture_false_integer_example` (supplement) are separately proved negations of the same `ClaimedLowerBound`.
