Object domains and standard meanings
------------------------------------
1. Patterns are actual finite permutations, with no repeated values. A faithful
   formal domain is Perm(k) = Equiv.Perm (Fin k), for positive natural k, together
   with its length. Positive lengths include length one. The source supplies no
   additional minimum length, shape constraint, class restriction, or hypothesis
   on either input. None may be silently introduced. If an implementation also
   includes an empty permutation, its convention must be explicit; it must not
   change the meaning on ordinary nonempty patterns or be used to manufacture
   an interpretation-dependent result. The explicit equality on all nonempty
   patterns is already an assertion of the source under the standard reading.

2. For p in Perm(k) and s in Perm(n), classical containment means that there is
   a strictly increasing position map e : Fin k -> Fin n such that, for every
   i,j : Fin k,

       s(e(i)) < s(e(j))  iff  p(i) < p(j).

   The selected positions need not be consecutive. Avoidance is the negation of
   this containment predicate. This is single classical permutation-pattern
   avoidance, not consecutive avoidance, a generalized pattern notion, repeated
   letter words, or avoidance of an arbitrarily chosen set of patterns.

3. Av_n(p) is the finite set of ALL s in Perm(n) that avoid p, and

       a_n(p) = |Av_n(p)|.

   There is no weighting, factorial normalization, probability normalization,
   additional subclass restriction, or replacement by all unrestricted
   permutations. Finiteness follows from the finite permutation domain.

4. The ordinary Stanley-Wilf limit in this single-pattern setting is the genuine
   real limit

       L(p) = lim_{n -> infinity, n >= 1} (a_n(p))^(1/n).

   In particular, the root is taken after coercing the count to a nonnegative
   real number and 1/n is real division. A limsup, exponential upper bound,
   logarithmic rate, or arbitrary assigned number cannot be substituted without
   proving the correspondence actually needed. Generic permutation-class
   literature may use an upper growth rate defined by a limsup; that does not
   authorize dropping genuine convergence for this named single-pattern limit.

5. If p has length k and q has length l, p direct-sum q is the permutation of
   length k+l whose first k positions have values p, and whose final l positions
   have values k+q. With zero-based entries the equations are

       (p direct-sum q)(i)   = p(i)        for i < k,
       (p direct-sum q)(k+j) = k + q(j)    for j < l.

   All values in the first block are smaller than all values in the second
   block, and all its positions precede those of the second block. This is an
   operation on patterns. It is not the Cartesian product or union of the two
   avoidance classes, nor the skew sum or a tensor product.

Precise assertion and limit formulation
--------------------------------------
Once L has been tied to these actual limits, the displayed assertion is exactly

  P := forall k,l in N with k>0 and l>0,
       forall p in Perm(k), forall q in Perm(l),
       L(p direct-sum q) = L(p) * L(q).

The universal quantifiers are part of the assertion even though the source uses
free pattern symbols. There are no additional hypotheses on p or q.

For a limit formulation that does not hide convergence in a totalized limit
operator, define

  b_p(n) := (a_{n+1}(p) : R) ^ (1 / ((n+1 : N) : R)),
  SW(p,x) := Tendsto b_p atTop (nhds x),  where x : R.

The index shift merely avoids the undefined ordinary zeroth root; its connection
to the positive-index source sequence must be explicit. A fully specified
relational version of the source's displayed limit equality is

  P_SW := forall k,l in N with k>0 and l>0,
          forall p in Perm(k), forall q in Perm(l),
          exists x,y,z in R,
            SW(p,x) and SW(q,y) and SW(p direct-sum q,z)
            and z = x*y.

This formulation includes the existence presupposed when the source writes its
three real limits. Uniqueness of genuine real limits supplies its identification
with the L formulation. A project may instead define L by a verified standard
construction and prove the needed SW specification. It must not assume a free
function L with unverified numerical values. For a disproof, the actual three
growth limits involved must be established; it is not necessary to formalize the
general existence theorem for every pattern merely to define unrelated limits.
Any final negation must be connected formally to the universal statement above,
rather than only to a conditional or a restricted replacement statement.
