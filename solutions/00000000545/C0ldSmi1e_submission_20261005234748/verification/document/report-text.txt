Quadratic Markov bases for complete graphs
A disproof of Conjecture 00000000545
C0ldSmi1e · 5 October 2026
Abstract
Under the standard edge-ring interpretation of graph ring, the proposed cutoﬀ at ﬁve vertices
is false. We prove that the toric ideal of every ﬁnite complete graph is generated by a ﬁnite
set of nonzero quadratic binomials. The proof connects every degree ﬁber by replacements
of two edges, with unrestricted edge multiplicities, and then establishes generation of the full
polynomial kernel. The argument works over every nontrivial commutative ring, hence over
every ﬁeld. In particular, K6 is a counterexample. The accompanying Lean 4 project checks
the entire argument.
1 The statement and the standard objects
The exact English source is:
Deﬁnition: Markov bases (quadratic-quadratic). Conjecture: The toric ideal of the
graph ring of Kn has an entirely quadratic Markov basis if and only if n ≤ 5 (a criterion
beyond Hosten–Sullivant).
The Chinese version states the same equivalence. Both original texts are preserved in ORIGINAL.md.
We interpret graph ring as the usual edge ring, with one generator xixj for each unordered pair of
distinct vertices. No assertion about a diﬀerent construction, such as a cut ring, is intended.
Let V be a ﬁnite set and let E = {{i, j } : i, j ∈ V, i ̸= j}, the edge set of the complete graph. Let

Markov basis; we also prove its degree-ﬁber connectivity directly.

2 Inserting an edge with quadratic switches
A quadratic replacement substitutes a two-edge multiset A by another two-edge multiset B with
∂A = ∂B, while retaining every other edge occurrence. Repeated edges are allowed. A replacement
with A = B is simply reﬂexive and will not be included as a generator.
Lemma 1 (Insertion). Suppose a ̸= b and ∂M = ∂({a, b } + Q). There is an edge multiset T ′ such
that at most two quadratic replacements transform M into {a, b } + T ′.
Proof. The vertex a occurs in ∂M , so remove one occurrence of an edge {a, c } from M . If c = b,
the desired edge is already present. Otherwise b is on neither endpoint of the removed edge, since
a ̸= b and c ̸= b. The equality of endpoint multisets therefore ensures that an occurrence of an
edge {b, d } remains. Remove it too, leaving S:
M = {a, c } + {b, d } + S.
These are removals of occurrences, so the assertion remains valid with arbitrary multiplicities.
If c ̸= d, make the replacement
{a, c } + {b, d } ↦− → { a, b } + {c, d }.
Both new edges are loopless, and the endpoint multiset is unchanged.
It remains to consider c = d. In this case c ̸= a and c ̸= b, because the two removed edges are
loopless. Let sc = (∂S)(c) and qc = (∂Q)(c). Comparing the count of the speciﬁc vertex c and then
the total endpoint counts gives
2 + sc = qc, |M | = |Q| + 1, |Q| = |S| + 1.
Since qc ≤ |Q|, we have 2 + sc ≤ |S| + 1, and hence sc < |S|. Consequently some edge of S avoids
c: if all its edges contained c, each would contribute exactly one to sc, yielding sc = |S|.
Remove an occurrence of such an edge {x, y } and write S = {x, y } + T . Interchange the names x, y
if necessary so that x ̸= a; this is possible because x ̸= y. We have c ̸= x and c ̸= y. The following
two replacements, carrying T along, are therefore valid:
{a, c } + {x, y } ↦− → { a, x } + {c, y },
{a, x } + {b, c } ↦− → { a, b } + {x, c }.
Every displayed edge is loopless: the additional inequalities needed are a ̸= x, c ̸= y, a ̸= b, and
x ̸= c, all already established. The ﬁnal multiset is {a, b } + {x, c } + {c, y } + T , as required. If an
intermediate replacement leaves its two-edge multiset unchanged, it is a zero-step move. Such a
case causes no problem and adds no zero binomial to the eventual basis.

3 All ﬁbers, with no degree bound
Theorem 2 (Quadratic connectivity) . For any edge multisets M, N , equality ∂M = ∂N implies
that a ﬁnite sequence of quadratic replacements transforms M into N .
Proof. Induct on |N |, with M arbitrary. If N is empty, then 2|M | = |∂M | = |∂N | = 0 , so M is
empty as well.
Otherwise remove one occurrence of an edge e = {a, b } from N and write N = e + Q. The insertion
lemma transforms M into e + T ′. Every replacement preserves its endpoint multiset, so
∂e + ∂T ′ = ∂M = ∂N = ∂e + ∂Q.
Cancel the common endpoint multiset ∂e to obtain ∂T ′ = ∂Q. The induction hypothesis transforms
T ′ into Q. Carry the common edge occurrence e along during each of these moves. Combining the
two ﬁnite sequences transforms M into N .
This induction concerns all nonnegative exponent vectors. In particular, it does not enumerate a
bounded collection of monomials or rely on a test of ﬁnitely many degree ﬁbers.

is nonzero, homogeneous of degree two, and has total degree exactly two.

4 The entire polynomial kernel
To pass from binomials to all kernel polynomials, the following general argument is included ex-
plicitly. It needs no restriction on polynomial degree and no assertion that the polynomial being
considered is itself a binomial.

Theorem 5 (The quadratic basis) . For every ﬁnite complete graph and every nontrivial commu-
tative ring k, the kernel of its edge-ring parametrization has a ﬁnite generating set B consisting en-
tirely of nonzero quadratic pure binomials. In particular, over every ﬁeld, B is an entirely quadratic
Markov basis.
Proof. Use the set B deﬁned above. Its ﬁniteness, the degree and nonvanishing of its members, and
the equality I = ( B) have all been established. Quadratic connectivity proves the corresponding
combinatorial Markov property as well.
No minimality of this generating set is claimed or needed. Including redundant nonzero generators,
or both signs of one binomial, is permitted in a Markov basis.

5 The counterexample and formal correspondence
Corollary 6. Conjecture 00000000545 is false: K6 has an entirely quadratic Markov basis, although
6 ̸≤ 5.
Proof. Take V = {0, 1, 2, 3, 4, 5} in the quadratic-basis theorem. The implication “has an entirely
quadratic Markov basis ⇒ n ≤ 5” fails. Since 6 > 0, the counterexample also applies when the
conjecture is quantiﬁed only over positive integers.
The formal proof uses Lean 4.19.0 and mathlib at commit
c44e0c8ee63ca166450922a373c7409c5d26b00b.
The package pins all dependencies. Its polynomial rings are mathlib’s MvPolynomial; the toric ideal
is the actual RingHom.ker. The correspondence between arbitrary edge multisets and natural ex-
ponent vectors is mathlib’s additive equivalence Multiset.toFinsupp. The property CompleteGraph.
HasQuadraticMarkovBasis explicitly requires a ﬁnite binomial set spanning this kernel, distinct ex-
ponent vectors, degree two for both monomials, and polynomial total degree two.
The principal declarations are as follows; module names indicate ﬁles, while every displayed qualiﬁed
theorem name is its actual Lean name.
• Connectivity.lean: edges are all cardinality-two vertex ﬁnsets. CompleteGraph.insert_edge
proves the insertion lemma, and CompleteGraph.connected_of_degree_eq proves unrestricted
ﬁber connectivity, including repeated edge occurrences.
• IdealBridge.lean: IdealBridge.ker_monomialMap_le_of_fiber_binomials proves the
arbitrary-polynomial kernel lemma. The substitution identity is
IdealBridge.toricMap_eq_eval2Hom.
• Conjecture545.lean: CompleteGraph.graphRingMap_edge identiﬁes the parametrization as
Y{i,j} ↦→ xixj. CompleteGraph.toricIdeal_eq_span_quadraticBinomials proves the full ideal
equality. The declarations CompleteGraph.quadraticBinomials_finite and
CompleteGraph.quadraticBinomials_totalDegree verify ﬁniteness and exact degree two.
• CompleteGraph.hasQuadraticMarkovBasis gives the general existence theorem, and
CompleteGraph.counterexample_six supplies K6. The ﬁnal positive-domain negation is
CompleteGraph.conjecture545_false_positive; the unrestricted natural-number version is
CompleteGraph.conjecture545_false.
