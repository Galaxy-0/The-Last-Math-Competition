# 00000000126

**English.** Conjecture: Generalized repunit primes: for every a ≥ 2 there are infinitely many primes of the form 1 + a + a² + … + a^k (k+1 prime being a necessary condition).

**中文。** 猜想：广义重单位素数:对每个 a ≥ 2,形如 1 + a + a² + … + a^k 的素数有无穷多个(k+1 为素数是必要条件)。

## Interpretation and scope

Length n is k+1 in the source. The proof covers every natural-number length, not merely a bounded computation. Infinitude of a set of natural-number prime values is expressed equivalently as unboundedness.
